# Railway Manager — vehicle illustration kit

Eight generated concept assets: CC201, CC203, CC206 (orange livery), Economy, Executive, Luxury, Generator, Dining.

`original/`: full resolution PNGs with transparency.
`webp/`: 640px-wide optimized alpha thumbnails used in prototype v3.
`manifest.json`: IDs and exact subject prompts.

Shared prompt: isolated single vehicle, strict horizontal left-facing side elevation, realistic illustrated 3D catalog style, transparent background, full couplers visible, no track/scenery/captions, upper-left studio light.

Illustrations need human review of model shape and livery before release. They are not technical drawings. Economy artwork uses a conventional white/orange concept; the current game catalog K3 Premium uses stainless steel, so select or revise the variant before production. CC203 has no catalog entry at the analyzed snapshot. No extra cargo artwork included.
